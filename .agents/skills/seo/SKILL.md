# SEO Skill Guide

## Principles
1. **Per-Page Metadata:** Title, meta description, canonical URL, and viewport on every public page.
2. **Open Graph & Twitter:** Complete `og:title`, `og:description`, `og:image`, `og:url`, and Twitter summary cards.
3. **Structured Data (JSON-LD):**
   - Homepage: `Person` + `WebSite`.
   - Projects: `CreativeWork` / `SoftwareSourceCode`.
   - Blog Posts: `Article` / `BlogPosting`.
4. **Search Crawler Assets:** Include valid `robots.txt` and automatic sitemap (`/sitemap-index.xml` or `/sitemap.xml`).
