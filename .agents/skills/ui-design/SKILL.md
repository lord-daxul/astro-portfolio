# UI Design Skill Guide

## Principles
1. **Design Hierarchy:** Establish visual weight through typography size, weight, line-height, and color contrast.
2. **Spacing Consistency:** Rely on defined token scales (e.g. `gap-4`, `p-6`, `space-y-8`, clamp-based paddings).
3. **No Fluff:** Avoid generic cards, decorative animations without purpose, and arbitrary gradients.
4. **Interaction States:** Provide clear hover, focus-visible, active, and disabled states on interactive elements.
5. **Mobile-First Layout:** Ensure all components stack cleanly with ergonomic touch targets (>= 44px).
